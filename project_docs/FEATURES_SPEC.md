# XFiles Pro — FEATURES SPECIFICATION (مواصفات الميزات المستهدفة)

يحدد هذا المستند كافة الميزات والوظائف الـ 23 المعتمدة في نطاق مشروع XFiles Pro والمتطلبات التفصيلية لكل منها.

---

### 1. إدارة الملفات والمجلدات الأساسية (File & Folder Operations)
- **العمليات الأساسية:** إنشاء مجلدات وملفات فارغة، نسخ، قص، لصق، إعادة تسمية، حذف (مباشر أو إلى سلة المحذوفات)، تحديد متعدد (Batch Operations).
- **عرض الخصائص:** فحص المسار الكامل، الحجم الفعلي والحجم على القرص، تاريخ الإنشاء والتعديل، الصلاحيات وقراءة الأذونات (POSIX/Attributes)، حساب عدد العناصر الفرعية للمجلدات وحجمها الإجمالي في الخلفية.
- **إدارة التعارض:** معالجة تضارب الأسماء عند النسخ/النقل (استبدال، تخطي، إعادة التسمية تلقائياً).

### 2. تصفح الذاكرة الداخلية وبطاقة SD والتخزين الخارجي (Storage Browsing)
- تصفح التخزين الداخلي الأساسي (`/storage/emulated/0`).
- اكتشاف بطاقات الذاكرة الخارجية (MicroSD) ومحركات أقراص USB OTG.
- استخدام Android Storage Access Framework (SAF) للحصول على أذونات الوصول الدائمة وحفظ الـ Persisted URI Permissions.
- عرض شريط مسار تفاعلي (Breadcrumbs) للتنقل السريع بين المجلدات الأب، مع دعم التمرير الأفقي وإمكانية كتابة المسار يدوياً.

### 3. التبويبات المتعددة والشاشات المقسمة (Multi-Tabs & Dual Pane)
- **نظام التبويبات:** دعم فتح عدة مسارات في تبويبات مستقلة مع حفظ حالة التمرير والتحديد لكل تبويب، والتبديل السلس بينها.
- **وضع الشاشة المزدوجة (Dual Pane):** عرض لوحين متجاورين للتصفح على الشاشات الكبيرة (الأجهزة اللوحية والوضع الأفقي)، يتيح السحب والإفلات (Drag & Drop) أو النسخ والنقل المباشر بين اللوحين.

### 4. الفهرسة الدائمة والبحث المتقدم (Persistent Indexing & Advanced Search)
- **قاعدة بيانات الفهرس:** جدول محلي سريع مدعوم بـ SQLite FTS5 (Full-Text Search) عبر Room Database.
- **التحديث التزايدي:** الاستماع لتغيرات الملفات عبر `ContentObserver` و`WorkManager` للمزامنة التزايدية الذكية دون إعادة مسح الهاتف بالكامل عند كل تشغيل.
- **تحديث الفهرس مع العمليات:** تحديث السجلات تلقائياً فور إتمام عمليات النسخ، النقل، وإعادة التسمية والحذف داخل التطبيق.
- **فلاتر البحث:** البحث السريع بالنص، والبحث المتقدم حسب النوع (صور، فيديو، صوت، مستندات، أرشيفات، APK)، الامتداد، نطاق الحجم، ونطاق التاريخ.
- **التصفح التدريجي:** استخدام مكتبة Paging لعرض آلاف النتائج دون استنزاف الذاكرة.

### 5. معرض الصور المدمج (Integrated Photo Gallery & Viewer)
- استعراض الصور بدقة كاملة مع دعم التكبير والتصغير بالإصبع (Pinch-to-zoom).
- عرض الصور المصغرة (Thumbnails) بكفاءة مع تخزين مؤقت متقدم (Caching).
- قراءة وعرض بيانات EXIF للصور (الكاميرا، الأبعاد، الموقع، وتاريخ الالتقاط).

### 6. عارض وتشغيل الفيديو والصوت والـ PDF (Media & Document Viewers)
- **مشغل الفيديو:** تشغيل صيغ MP4, MKV, WebM مع التحكم في الصوت، السطوع، والتقديم/التأخير.
- **مشغل الصوت:** تشغيل الملفات الصوتية في الخلفية مع واجهة مصغرة وعرض معلومات المقطع (ID3 tags).
- **قارئ PDF:** عارض صفحات PDF مدمج يدعم التمرير الرأسي، والبحث داخل المستند، والقفز لرقم الصفحة.

### 7. محرر النصوص والأكواد (Text & Code Editor)
- فتح وتعديل ملفات النصوص البرمجية (TXT, JSON, XML, HTML, MD, Kotlin, Java, Python, Log).
- ترقيم الأسطر، تلوين البناء النحوي (Syntax Highlighting)، التفاف الأسطر التلقائي.
- البحث والاستبدال، واختيار ترميز الأحرف (UTF-8, UTF-16, ASCII).

### 8. إدارة وضغط وفك الأرشيفات (Archive Management)
- استعراض محتويات ملفات الأرشيف كأنها مجلدات دون الحاجة لفك الضغط بالكامل.
- دعم الصيغ الشائعة: ZIP, TAR, GZ, 7Z, RAR (قراءة).
- إنشاء أرشيفات ZIP و7Z مع خيارات لمستوى الضغط وتعيين كلمة مرور.
- استخراج محدد لملفات معينة أو فك الضغط الشامل مع إظهار شريط تقدم تفاعلي.

### 9. مدير التنزيلات المدمج (Integrated Download Manager)
- تنزيل الملفات عبر الروابط المباشرة (HTTP/HTTPS) مع دعم الاستئناف (Resume capability).
- إدارة قائمة التنزيلات (إيقاف مؤقت، متابعة، إلغاء)، وإشعارات شريط الحالة بتقدم التحميل.

### 10. إدارة التطبيقات وملفات APK (App & APK Manager)
- عرض قائمة بجميع التطبيقات المثبتة (تطبيقات النظام وتطبيقات المستخدم).
- استخراج ملفات الـ APK وحفظها كنسخة احتياطية على الذاكرة.
- تثبيت تطبيقات APK عبر Intent رسمي آمن مع التحقق من الأذونات.
- عرض تفاصيل الحزمة (اسم الحزمة، رقم الإصدار، الـ SDK المستهدف، والصلاحيات المطلوبة).

### 11. مستكشف حزم APK واستخراج الموارد (APK Explorer & Asset Extractor)
- فحص البنية الداخلية لملفات APK (AndroidManifest.xml، ومجلد `res/`، والأصول `assets/`، وملفات `classes.dex`).
- استخراج الموارد والأيقونات والملفات الفردية من حزم التطبيقات.

### 12. التكامل مع نظام فتح الملفات في أندرويد (Intent Filters & MIME Types)
- تسجيل التطبيق للتعامل مع إجراءات `ACTION_VIEW` و`ACTION_GET_CONTENT` لمختلف أنواع الوسائط والمستندات.
- معالجة الـ Content URIs بأمان عبر واجهات `ContentResolver`.

### 13. استقبال الملفات عبر Android Sharesheet
- تسجيل التطبيق لمعالجة إجراءات `ACTION_SEND` و`ACTION_SEND_MULTIPLE`.
- إتاحة حفظ الملفات المستلمة في أي مجلد يختاره المستخدم أو إضافتها للخزنة.

### 14. أداة تحليل التخزين (Storage Analyzer)
- تحليل توزيع استهلاك السعة التخزينية وتصنيفها (صور، فيديو، صوت، مستندات، تطبيقات، ملفات أخرى).
- مخططات ورسوم بيانية تفاعلية بنظام Material 3 توضح نسب الاستهلاك وتتيح التعمق في المجلدات الأكثر استهلاكاً.

### 15. كاشف الملفات المكررة والملفات الكبيرة (Duplicate & Large Files Cleaner)
- فحص الملفات الضخمة التي تتجاوز حجماً محدداً (مثلاً > 100 ميجابايت).
- اكتشاف الملفات المكررة بدقة من خلال مقارنة الحجم ثم حساب بصمة الهاش (MD5/SHA-256) للملفات المتطابقة في الحجم لتجنب الإيجابيات الزائفة.
- واجهة آمنة لاختيار النسخ المراد حذفها مع طلب تأكيد مسبق.

### 16. الخزنة الخاصة والتشفير الآمن (Secure Vault & Encryption)
- مساحة مشفرة محمية ومفصولة تماماً عن متناول التطبيقات الأخرى.
- التشفير المتماثل القوي AES-256 GCM مع إدارة المفاتيح داخل Android Keystore الآمن للعتاد.
- قفل الخزنة برمز مرور (PIN/Password) مع دعم المصادقة الحيوية (BiometricPrompt - بصمة الإصبع/الوجه).
- الحذف الآمن (Secure File Shredding) للملف الأصلي عند نقله إلى الخزنة.

### 17. نقل الملفات عبر Wi-Fi المحلي (Local Wi-Fi File Sharing)
- إنشاء خادم ويب محلي (HTTP/WebDAV) على شبكة Wi-Fi المحلية للمستخدم دون الحاجة لاتصال خارجي بالإنترنت.
- توفير واجهة ويب سهلة تتيح للحاسوب أو الأجهزة الأخرى على نفس الشبكة رفع وتنزيل الملفات عبر المتصفح باستخدام عنوان IP ورقم المنفذ أو رمز QR.

### 18. بروتوكولات الاتصال والشبكات (Network Protocols Client)
- عميل للاتصال بخوادم FTP وSFTP وSMB (Windows Sharing) وWebDAV.
- تصفح المجلدات البعيدة وإجراء عمليات النقل والتنزيل والرفع المباشر كأنها ملفات محلية.

### 19. الأدوات المتقدمة ومقارنة الملفات وحساب الهاش (Advanced Tools & Hash)
- حاسبة التجزئة الرقمية (Hash Calculator): دعم خوارزميات MD5, SHA-1, SHA-256, CRC32 لمطابقة سلامة الملفات.
- مقارن الملفات (File Comparator): مقارنة ملفين ثنائياً أو نصياً لتحديد الفروقات بينهما.

### 20. سلة المحذوفات القابلة للاستعادة (Recycle Bin / Soft Delete)
- مجلد خاص محلي للمحذوفات المؤقتة يحافظ على المسار الأصلي للملف.
- إمكانية استعادة الملفات إلى مساراتها السابقة بدقة أو إفراغ السلة نهائياً، مع دعم الجدولة الزمنية لتنظيف المحذوفات القديمة تلقائياً.

### 21. النسخ الاحتياطي والاستعادة (Backup & Restore)
- تصدير واستيراد إعدادات التطبيق، والمفضلات (Bookmarks)، وقواعد الفهرسة، وسجل الملاحظات إلى ملف محلي مشفر أو مضغوط.

### 22. الأمان والخصوصية وحماية البيانات (Security & Privacy)
- عدم طلب أذونات التخزين الشامل دون توضيح، وتفضيل واجهات SAF الرسمية.
- انعدام التتبع (No telemetry) وعدم إرسال أي بيانات عن ملفات المستخدم لأي طرف خارجي.
- عزل مفاتيح التشفير وكلمات المرور المشفرة داخل Android Keystore بنظام التجزئة الآمن PBKDF2 / Argon2.

### 23. اللغات والسمات والتخصيص البصري (Localization & Themes)
- **نظام اللغات:**
  - دعم 4 لغات: العربية (RTL)، الإنجليزية (LTR)، الإسبانية (LTR)، الفارسية (RTL).
  - شاشة اختيار لغة مستقلة ومصممة بعناية تظهر عند أول تشغيل وتخزن الاختيار دون تكرار ظهورها.
  - تطبيق التغيير فورياً دون إعادة تشغيل التطبيق أو فقدان الحالة.
  - استخدام نظام موارد نصوص مركزي (`strings.xml`) دون نصوص مضمنة يدوياً (Hardcoded).
- **نظام السمات:**
  - 4 سمات معتمدة:
    1. **Classic:** واجهة أبيض وأسود أنيقة عالية التباين (السمة الافتراضية).
    2. **Midnight:** واجهة داكنة متطورة تركز على الأسود العميق لتقليل استهلاك شاشات AMOLED.
    3. **Royal:** واجهة فاخرة من الأسود اللامع مع لمسات ذهبية ملكية.
    4. **System:** تتبع سمة نظام أندرويد تلقائياً (Light / Dark مع Dynamic Colors).
  - حفظ واستعادة السمة المختارة فورياً عبر DataStore.
