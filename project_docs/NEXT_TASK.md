# XFiles Pro — NEXT TASK (المهمة التالية المحددة بدقة)

## المهمة الحالية المستهدفة: الانتقال إلى المرحلة الخامسة بموافقة المستخدم (Phase 5)

### عنوان المرحلة:
**المجموعة الثانية - المرحلة 5A والمرحلة 5B: محرك الملفات وواجهات التخزين والفهرسة الدائمة (Storage Engine & Persistent Indexing)**

> **تنبيه حاسم:** المرحلة الرابعة (الواجهة الرئيسية وهيكل التنقل) **اكتملت بنجاح 100%** مع تمرير كافة الاختبارات الـ 75. المرحلة الخامسة **لم تبدأ بعد**، وهي متوقفة تماماً بانتظار توجيه وموافقة المستخدم الصريحة للانطلاق.

---

### 1. الهدف من المرحلة الخامسة (Phase Objective)
بناء محرك الملفات الحقيقي القادر على تصفح وحدات التخزين (Internal Storage, SD Card, USB OTG) عبر File APIs و Storage Access Framework (SAF)، وإجراء عمليات الـ CRUD الأساسية (إنشاء مجلد/ملف، نسخ، نقل، حذف، إعادة تسمية) مع محرك الفهرسة الدائم المدعوم بـ Room و SQLite FTS5 للبحث الفوري دون استنزاف البطارية أو الذاكرة.

---

### 2. نطاق العمل المحدد للمرحلة الخامسة (Exact Scope)
1. **المرحلة 5A: محرك الملفات وواجهات التخزين:**
   - قراءة مسارات التخزين الفعلية والحصول على أذونات SAF الدائمة (`takePersistableUriPermission`).
   - تنفيذ عمليات الملفات الأساسية مع معالجة التعارض والأسماء المكررة.
   - تشغيل كافة عمليات القراءة والكتابة والنسخ في الخلفية عبر `Dispatchers.IO`.
2. **المرحلة 5B: الفهرسة الدائمة للملفات (Persistent Indexing Engine):**
   - استكمال جداول Room وقاعدة بيانات `XFilesDatabase` مع جدول FTS5 للبحث النصي فائق السرعة.
   - استخراج البيانات الوصفية (الاسم، الامتداد، الحجم، تاريخ التعديل، والنوع).
   - التحديث التلقائي للفهرس تزامناً مع أي عملية تتم داخل التطبيق.
3. **الاختبارات:**
   - اختبارات وحدة وRobolectric لعمليات الملفات واستعلامات الفهرس.

---

### 3. معايير القبول للمرحلة الخامسة (Acceptance Criteria)
- [ ] تصفح حقيقي لمسارات التخزين الداخلية والخارجية.
- [ ] إجراء عمليات الملفات الأساسية بأمان ودون تجميد للواجهة.
- [ ] فهرسة سريعة للبيانات في Room مع استعلامات FTS5.
- [ ] الحفاظ التام على وظائف اللغات والسمات والتنقل السابقة بنسبة 100%.
- [ ] نجاح البناء وتمرير كافة الاختبارات.
- [ ] تحديث ملفات التوثيق.
