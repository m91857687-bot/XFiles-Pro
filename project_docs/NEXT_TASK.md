# XFiles Pro — NEXT TASK (المهمة التالية المحددة بدقة)

## المهمة التالية المستهدفة: المرحلة 8 (Phase 8) — بانتظار موافقة المستخدم الصريحة

### عنوان المرحلة:
**المجموعة الثانية - المرحلة 8: مدير التنزيلات المدمج (Integrated Download Manager)**

> **تنبيه حاسم:** المرحلة السابعة (إدارة وضغط وفك واستعراض الأرشيفات) **اكتملت ودُققت بنجاح 100%** مع تمرير كافة الاختبارات الـ 163 بنجاح تام (0 failures, 0 errors). المرحلة 8 **لم تبدأ بعد**، وهي متوقفة تماماً بانتظار توجيه وموافقة المستخدم الصريحة للانطلاق.

---

### 1. الهدف من المرحلة 8 (Phase Objective)
بناء مدير تنزيلات قوي ومتعدد المهام ومدمج بسلاسة داخل XFiles Pro يدعم استئناف التنزيلات، التنزيل متعدد الخيوط المجزأ (Multi-threaded segmented downloading)، مراقبة السرعة وحجم البيانات المتبقي، والتحكم الذاتي في التنزيل في الخلفية عبر Foreground Service و WorkManager.

---

### 2. نطاق العمل المحدد للمرحلة 8 (Exact Scope)
1. **محرك التنزيل متعدد الخيوط والاتصالات (`data/local/download/`):**
   - دعم التنزيل المجزأ (Segmented HTTP Range requests).
   - استئناف التنزيل التلقائي عند انقطاع الاتصال (Resume support).
   - مراقبة وحساب سرعة التنزيل والوقت التقديري المتبقي (ETA).
2. **الخدمة الخلفية والتنبيهات (`Foreground Service & Notifications`):**
   - تنزيل مستقر ومستمر حتى مع إغلاق التطبيق.
   - إشعارات تفاعلية بنسبة التقدم وأزرار تحكم (إيقاف مؤقت، استئناف، إلغاء).
3. **قاعدة البيانات وسجل التنزيلات (`Room Database & DownloadDao`):**
   - حفظ بيانات المهام، الحالات (`QUEUED`, `DOWNLOADING`, `PAUSED`, `COMPLETED`, `FAILED`, `CANCELLED`).
4. **طبقة واجهة المستخدم (UI & MVVM):**
   - شاشة إدارة التنزيلات مع تبويبات (النشطة، المكتملة، المتوقفة).
   - نافذة إضافة رابط تنزيل جديد مع خيارات مسار الحفظ وتحديد عدد الأجزاء.
5. **حزم الاختبارات:**
   - اختبارات وحدة وRobolectric لمحرك التجزئة، إدارة الحالة، واستئناف التنزيل.
