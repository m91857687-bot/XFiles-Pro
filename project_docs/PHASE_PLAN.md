# XFiles Pro — PHASE PLAN (خطة المجموعات والمراحل التنفيذية)

تم تقسيم مشروع **XFiles Pro** إلى 5 مجموعات تضم 15 مرحلة هندسية متتالية، تضمن التدرج المنهجي وعدم القفز إلى الميزات المتقدمة قبل اكتمال البنية التحتية.

---

## المجموعة الأولى: تأسيس التطبيق وتصميمه (Foundation & Architecture)

### المرحلة 1: تأسيس المشروع والمعمارية (Project Setup & Architecture) — [مكتملة بنجاح ✅]
- ضبط إعدادات Gradle والتبعيات في `libs.versions.toml`.
- إعداد هيكل الحزم للطبقات الثلاث (Domain, Data, UI).
- إنشاء النماذج الأساسية (`FileItem`, `StorageVolume`, `ResultWrapper`).
- تجهيز فئات التزامن (`CoroutineDispatchers`) وتوفير التبعيات.

### المرحلة 2: نظام اللغات الشامل (Localization System) — [مكتملة بنجاح ✅]
- إعداد دعم اللغات الأربع: العربية (ar)، الإنجليزية (en)، الإسبانية (es)، الفارسية (fa).
- إنشاء شاشة الترحيب واختيار اللغة عند أول تشغيل (First-Run Language Screen).
- حفظ واستعادة اللغة المختارة عبر DataStore.
- تطبيق تغيير اللغة فورياً مع دعم اتجاهات الكتابة RTL و LTR.
- إنشاء ملفات الموارد المركزية لجميع النصوص (`values`, `values-ar`, `values-es`, `values-fa`).

### المرحلة 3: نظام السمات البصرية (Theming System) — [مكتملة بنجاح ✅]
- تنفيذ السمات الأربع المعتمدة:
  1. **Classic:** أبيض وأسود عالي التباين (Default).
  2. **Midnight:** واجهة داكنة عالية التباين لشاشات AMOLED.
  3. **Royal:** أسود فاخر مع ذهبي ملكي.
  4. **System:** تتبع سمة النظام والديناميكية.
- ربط السمات بـ DataStore لحفظ واسترجاع تفضيل المستخدم فورياً بدون وميض.
- توحيد عناصر التصميم على مستوى Jetpack Compose بدون ألوان ثابتة متناثرة ونظام Color Tokens مركزي.
- تكامل تام مع نظام اللغات الـ 16 تركيبة و 58 اختباراً ناجحاً بنسبة 100%.

### المرحلة 4: الواجهة الرئيسية وهيكل التنقل (Main UI Shell & Navigation) — [مكتملة بنجاح ✅]
- تصميم الإطار الرئيسي التكيفي للتطبيق (Adaptive Scaffold): شريط تنقل سفلي للهواتف وشريط جانبي NavigationRail للشاشات العريضة والأجهزة اللوحية (>= 600dp).
- شريط علوي موحد (XFilesTopAppBar) يضم الهوية، عنوان القسم، نقطة ربط البحث الفوري، تبديل وضع العرض (List/Grid)، وقائمة الخيارات.
- لوحة وصول سريع ديناميكية تضم 8 أقسام رئيسية (الذاكرة الداخلية، بطاقة SD، الصور، الفيديوهات، الصوتيات، المستندات، التنزيلات، التطبيقات).
- هيكل التوجيه والتنقل عبر 5 وجهات أساسية (`HOME`، `FILES`، `MEDIA`، `TOOLS`، `SETTINGS`) مع شاشاتها المخصصة (`HomeScreen`, `FilesScreen`, `MediaScreen`, `ToolsScreen`, `SettingsScreen`).
- شريط مسار المجلدات التفاعلي (Interactive Breadcrumbs Bar) مع دعم التمرير الأفقي والقفز التفاعلي بين المستويات.
- معالجة زر الرجوع الذكي (Predictive/Adaptive BackHandler) للعودة السلسة إلى الشاشة الرئيسية قبل مغادرة التطبيق.
- تكامل تام مع اللغات الأربع (ar, en, es, fa) والسمات الأربع (Classic, Midnight, Royal, System) مع الحفاظ على الاتجاه وتحديث الرموز.
- 17 اختباراً إضافياً شاملاً (75 اختباراً ناجحاً بنسبة 100%).

## المجموعة الثانية: محرك إدارة الملفات (File Management & Indexing Engine)

### المرحلة 5A: محرك الملفات وواجهات التخزين (Storage Engine & File CRUD)
- بناء محرك قراءة الملفات عبر File APIs و Android Storage Access Framework (SAF).
- استخراج المسارات الفعلية ووحدات التخزين (Internal Storage, SD Card, USB OTG).
- تنفيذ عمليات الملفات الأساسية: إنشاء مجلد/ملف، نسخ، نقل، حذف، إعادة تسمية.
- إدارة تضارب الأسماء والصلاحيات وتقدم العمليات عبر Notification/Progress.

### المرحلة 5B: الفهرسة الدائمة للملفات (Persistent File Indexing Engine)
- بناء قاعدة بيانات Room مع جدول FTS5 للبحث السريع.
- محرك استخراج البيانات الوصفية (Metadata Extractor: الاسم، الامتداد، الحجم، التاريخ، التصنيف).
- آلية التحديث التزايدي الذكي باستخدام `ContentObserver` و `WorkManager`.
- تحديث الفهرس فورياً بعد عمليات الملفات الداخلية لضمان دقة البيانات دائماً.

### المرحلة 6: البحث السريع، التبويبات المتعددة والشاشات المقسمة (Search, Tabs & Dual Pane)
- واجهة البحث السريع والفلاتر الفورية (نوع الملف، الحجم، التاريخ).
- نظام التبويبات المتعددة (Multi-Tabs) وحفظ حالة كل تبويب ومساره.
- وضع الشاشة المزدوجة (Dual Pane) للأجهزة اللوحية والوضع الأفقي مع دعم السحب والإفلات.

### المرحلة 7: إدارة وضغط وفك الأرشيفات (Archive Management)
- استعراض الأرشيفات (ZIP, TAR, GZ, 7Z, RAR) كمجلدات افتراضية.
- ضغط المجلدات والملفات إلى ZIP و 7Z مع خيارات الضغط وكلمة المرور.
- فك الضغط الانتقائي والشامل في الخلفية مع شريط تقدم غير حاجب للواجهة.

### المرحلة 8: مدير التنزيلات المدمج (Download Manager)
- محرك تنزيل عبر روابط الويب المباشرة مع دعم استئناف التنزيل.
- قائمة التنزيلات النشطة والمكتملة والتنبيهات.

## المجموعة الثالثة: إدارة التطبيقات وعرض الملفات (App Management & Viewers)

### المرحلة 9: إدارة التطبيقات وملفات APK (App Manager & APK Explorer)
- عرض قائمة التطبيقات المثبتة واستخراج ملفات APK كنسخ احتياطية.
- مستكشف حزم APK لفحص ملفات المانيفست والموارد والأصول.
- تثبيت وتحديث حزم التطبيقات عبر الـ Intents الرسمية الآمنة.

### المرحلة 10: عارض الملفات ومحرراتها المدمجة (Built-in Viewers & Editors)
- معرض الصور عالي الأداء مع التكبير وعرض EXIF.
- مشغل الفيديو والصوت المدمج مع ضوابط التشغيل.
- قارئ مستندات PDF.
- محرر الأكواد والنصوص مع تلوين الأكواد والبحث وترقيم الأسطر.

### المرحلة 11: أداة تحليل التخزين والملفات المكررة (Storage Analyzer & Cleaner)
- رسم بياني دائري وشجري لتوزيع استهلاك المساحة التخزينية.
- فحص وحساب الهاش لاكتشاف الملفات المكررة والملفات الضخمة وتسهيل تنظيفها بأمان.

## المجموعة الرابعة: الميزات الاحترافية (Pro Features & Networking)

### المرحلة 12: الخزنة المشفرة والأمان المتقدم (Secure Vault & Keystore)
- تشفير AES-256-GCM متكامل مدعوم بـ Android Keystore.
- حماية الخزنة برمز مرور وبصمة الإصبع الحيوية.
- عزل الملفات والحذف الآمن المتعدد للملفات الأصلية.

### المرحلة 13: نقل الملفات عبر الشبكة وبروتوكولات الاتصال (Networking & Wi-Fi Sharing)
- خادم ويب محلي (HTTP/WebDAV) لنقل الملفات عبر Wi-Fi مع واجهة متصفح ورمز QR.
- عميل بروتوكولات FTP و SFTP و SMB و WebDAV للاتصال بوحدات التخزين الشبكية.

### المرحلة 14: الأدوات المتقدمة وسلة المحذوفات والنسخ الاحتياطي (Tools & Recycle Bin)
- حاسبة الهاش (MD5, SHA1, SHA256) ومقارن الملفات الثنائية والنصية.
- سلة المحذوفات مع ميزة الاستعادة الدقيقة لمساراتها السابقة وجدولة التنظيف.
- تصدير واستيراد النسخ الاحتياطية للإعدادات والمفضلات.
